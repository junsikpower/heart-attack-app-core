# Heart Attack v2 — 게임 기획서

## 1. 한 줄 정의

**"말로 상대의 심장을 두근거리게! 내 심장은 들키지 말고."**

1:1 음성 대화 게임입니다. 카드를 골라 상대에게 말을 걸고, 듣는 사람의 심박이 평소보다 얼마나 올랐는지로 점수를 겨룹니다.

## 2. 지키는 원칙

| 원칙 | 구현 방식 |
|---|---|
| 화상/랜덤채팅처럼 보이지 않기 | 영상 없음, 사진 없음, 나이·성별·지역 입력 없음 |
| 부담 없이 시작하기 | 닉네임 + 캐릭터(하트 버디) 색만 정하면 바로 플레이 |
| 대화가 어색하지 않기 | 토크 카드 35장(웃음/반전/뭉클/설렘/미션)이 대화를 이끔 |
| 게임으로서의 재미 | 공수 교대 턴제, 두근 미터, 점수, 결과 공개, 한 판 더 |
| 공정한 측정 | 말하는 사람이 아닌 **듣는 사람만** 측정 |
| 워치 확장성 | 측정 장치를 `HeartRateSource` 인터페이스로 추상화 |

## 3. 한 판의 흐름 (약 5분)

```
대기실: 둘 다 뒷면 카메라에 손가락 → 측정 잡히면 '준비 완료' → 3초 뒤 자동 시작
  ↓
숨 고르기 15초: 둘 다 조용히 → 각자의 기준 심박(평균) 측정
  ↓
┌ 턴 × 6 (3라운드, 호스트·게스트 번갈아 공격) ─────────────┐
│ 카드 고르기 10초 : 공격자가 서로 다른 종류 카드 3장 중 1장 선택 │
│ 공격 30초       : 공격자는 카드대로 말하기, 방어자는 듣기만     │
│                   → 방어자의 심박만 채점                    │
│ 결과 공개 4초    : 이번 턴 점수 공개                         │
└──────────────────────────────────────────────┘
  ↓
최종 결과: 승패, 오늘의 두근 모먼트, 턴별 그래프, 한 판 더
```

## 4. 점수 규칙

- **기본 점수**: 공격 중 1초마다 `(방어자 현재 심박 − 기준) ÷ 기준 × 100`(%)만큼 공격자가 점수를 얻습니다.
  - 예: 기준 70, 현재 77이면 +10%이므로 그 1초에 10점입니다.
- **상한**: 1초에 최대 30점입니다. 측정이 한 번 튀어도 승부가 갈리지 않게 하기 위해서입니다.
- **하한**: 기준보다 낮으면 0점입니다. 마이너스는 없습니다.
- **손 떼기 페널티**: 손가락을 떼도 3초까지는 봐줍니다. 그 뒤로는 숨긴 것으로 간주해 1초마다 공격자에게 10점을 줍니다.
- **정보 비대칭**:
  - 공격자는 상대의 정확한 숫자 대신 5단계 두근 미터만 봅니다(잔잔/살랑/두근/쿵쾅/심쿵).
  - 방어자는 자기 숫자를 보면서 포커페이스를 연습할 수 있습니다.
- **승리**: 6턴 합계 점수가 높은 사람이 이깁니다.

규칙 상수는 `lib/core/rules.dart` 한 파일에 모여 있어서 밸런스를 쉽게 조정할 수 있습니다.

## 5. 시스템 구조

```
lib/
 ├ core/          규칙(rules), 카드(cards), 디자인 토큰(theme)
 ├ heart/         측정 장치 추상화
 │   ├ heart_rate_source.dart       공통 인터페이스 (HeartReading 스트림)
 │   ├ camera_ppg_source.dart       카메라 PPG (기존 알고리즘 그대로)
 │   ├ camera_service.dart          후면 카메라 + 플래시, 측정 알고리즘
 │   └ watch_heart_rate_source.dart 워치 (자리만 마련)
 ├ multiplayer/   방 데이터 모델, Firebase 저장소, Agora 음성
 ├ providers/     프로필, 심박, 세션(게임 진행)
 └ ui/            화면, 시트, 위젯
```

**역할 분담: "호스트는 시계, 방어자는 채점관"**
- **호스트**: 서버 시각을 기준으로 페이즈를 넘깁니다.
- **방어자**: 자기 폰에서 잰 심박으로 직접 채점합니다. 원본 심박이 네트워크를 거치지 않아 가장 정확합니다.
- **모든 플레이어**: 1초마다 자기 심박을 공유합니다. 상대 화면의 두근 미터에 쓰입니다.

**Firebase 데이터 구조**: `room_models.dart` 상단 주석에 정리되어 있습니다. 보안 규칙 예시는 `database.rules.json`에 있습니다.
